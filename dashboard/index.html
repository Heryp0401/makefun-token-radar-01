Token Radar

Every pre-token protocol the snapshot records, ranked by the value its token may launch at. No token, no guess from a name: the value follows from the protocol's own TVL, its seven-day growth and how long it has run with no token.

How the implied value is modelled

Each protocol's implied value is its TVL times a multiple, times a growth multiplier, times a maturity multiplier. The multiple is calibrated per category from the snapshot's own traded protocols: the median market-cap-to-TVL ratio of that category's protocols whose token already trades, shrunk toward the global median (weight 4) so a category with one or two traded protocols cannot set an extreme multiple, and winsorised into [0.02, 2.0]. A category with no traded protocol takes the global median. Growth is the seven-day TVL change clamped to [-60, +120] per cent, weighted 0.5. Maturity rises from 0.6 for a new protocol to 1.0 at three years; an unknown listing date counts as one year.

implied = TVL × multiplecategory × (1 + clamp(change7d, -60, 120) / 100 × 0.5) × (0.6 + min(age, 1095) / 1095 × 0.4)
